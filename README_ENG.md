## 👋 About Me

I hold a degree in **Systems Analysis and Development**, with professional experience in **technical support, incident analysis, troubleshooting, technical documentation, and continuous improvement**.

I am currently transitioning into **Software Quality Assurance (QA)**, developing practical skills in **manual testing, test automation, API testing, and web application testing**.

My background in **JavaScript, TypeScript, and software development** helps me understand how applications work beyond the user interface, investigate unexpected behaviors, and design more comprehensive test scenarios.

Throughout my experience as a **Technical Support Analyst**, I have developed a problem-solving mindset focused on root cause analysis, system behavior, technical communication, and user experience.

My goal is to combine these skills to contribute to the **reliability, stability, and overall quality of software applications**, while continuously growing as a QA professional.
