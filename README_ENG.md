# Gustavo Favero

Software Developer in training and **Systems Analysis and Development** student.

I have hands-on experience as an IT Support Analyst, working with technical support, incident analysis, process improvement, and Agile methodologies (Scrum). Currently, I focus my studies and personal projects on Back-end development with Node.js, using JavaScript and TypeScript to build APIs, integrate services, and develop scalable applications.

I also build projects with React and React Native, aiming to understand the entire software development lifecycle, from user interfaces to back-end development, databases, version control, testing, and deployment.

My interests include software architecture, REST APIs, SQL and NoSQL databases, Docker, Linux, and software development best practices. I also study complementary areas such as Software Quality Assurance (QA), test automation, DevOps, and infrastructure to gain a broader understanding of the software lifecycle.

My goal is to transform knowledge into practical experience through real-world projects, technical documentation, and continuous learning.

Feel free to explore my repositories. They showcase my journey as a developer and the projects I use to experiment with new technologies, apply best practices, and strengthen my technical skills.
